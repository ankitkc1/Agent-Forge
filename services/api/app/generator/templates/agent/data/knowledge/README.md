# Knowledge sources

Each directory below is an approved retrieval source declared in `agent-spec.yaml`. Add Markdown
(`.md`), text (`.txt`) or reStructuredText (`.rst`) files; documents are chunked, scanned for
instruction-like content (quarantined if found), embedded and indexed.

The seed documents generated by AgentForge are **illustrative samples**. Replace them with your
organisation's approved documents before production use.

Only files inside a declared source directory are indexed; the agent cannot read anything else.
